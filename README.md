## Primo progetto: CSV to Excel Report

Script Python che legge un file CSV contenente transazioni, calcola i totali e genera automaticamente un report Excel formattato.

### Funzionalità
- Lettura dati da CSV
- Calcolo totale complessivo
- Calcolo totale pagato
- Calcolo totale in attesa
- Generazione file Excel
- Formattazione automatica colonne e importi
